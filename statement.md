# Project Statement

## Problem Statement
A simple Python expense tracker that records daily expenses, groups them by category, calculates totals, and gives a basic spending summary.

## Scope
The project provides a small command-line solution for the stated problem. It focuses on basic input, processing, storage, validation, and output. It does not attempt to replace a large real-world production system.

## Target Users
Students who want to understand and monitor everyday spending.

## High-Level Features
- Expense Entry
- Expense Storage
- Category Analysis & Summary

## Academic Relevance
The project demonstrates problem decomposition, algorithms, functions, conditional statements, loops, file handling, data structures, validation, modular programming, and basic testing in Python.
