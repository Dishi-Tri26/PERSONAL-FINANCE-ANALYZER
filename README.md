## Overview
A simple Python expense tracker that records daily expenses, groups them by category, calculates totals, and gives a basic spending summary.

## Functional Modules
1. Expense Entry
2. Expense Storage
3. Category Analysis & Summary

## Technologies
- Python 3
- Python standard library
- CSV files for simple storage
- No external packages

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run:
   `python main.py`

## Testing
Run:
`python test_project.py`

## Folder Structure
- `main.py` - main menu / program entry
- Supporting `.py` files - separate modules
- Data files - simple project data
- `test_project.py` - basic validation tests
- `statement.md` - project statement
- `README.md` - project documentation
- `requirements.txt` - dependency list

## Beginner-Level Design
The project intentionally uses simple functions, lists/dictionaries, loops, conditions, CSV storage, and straightforward validation. It is designed to demonstrate first-year problem-solving concepts rather than advanced software engineering.
